# Lista maestra de publicación

## Producto común

- [x] Aplicación gratuita, sin suscripción, anuncios ni compras integradas.
- [x] Español, inglés, portugués y chino simplificado.
- [x] Historial y procesamiento local.
- [x] Aviso clínico y referencias visibles.
- [x] Repositorio de código publicado.
- [ ] Política de privacidad accesible públicamente y revisada para esta aplicación.
- [ ] Capturas finales en teléfono y escritorio.
- [ ] Prueba funcional completa con datos ficticios.

## Android

- [x] `targetSdk 36`, identificador estable y configuración de firma externa al repositorio.
- [x] Ficha y declaraciones preliminares en cuatro idiomas.
- [ ] AAB release 1.4.0 firmado con la clave de carga original.
- [ ] APK release 1.4.0 firmada para AppGallery y pruebas directas.
- [ ] Verificación de firma y huella del certificado.
- [ ] Prueba en teléfono real, incluyendo funcionamiento sin conexión.
- [ ] Google Play: seguridad de datos, clasificación, público objetivo y prueba cerrada cuando corresponda.
- [ ] AppGallery: ficha, privacidad, clasificación, capturas y revisión.

## Windows / PWA

- [x] Manifiesto PWA, iconos, service worker y modo independiente.
- [x] Acceso visible a la versión Windows e instrucciones de instalación.
- [x] Sin dependencia de una cuenta o servidor para el historial.
- [ ] Publicar la última versión en la URL HTTPS de producción.
- [ ] Instalar y probar desde Edge/Chrome en Windows 10 y 11.
- [ ] Si se publica en Microsoft Store, generar y firmar el paquete con la identidad de Partner Center.

## Web de AME HEALTH

- [ ] Añadir botones para abrir/instalar Windows, Google Play y AppGallery.
- [ ] Ofrecer APK directa solo como alternativa, con versión, tamaño, fecha y SHA-256.
- [ ] Mantener como recomendación principal las tiendas oficiales para evitar alertas de origen desconocido.
